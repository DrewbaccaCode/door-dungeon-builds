# One Thousand Door Dungeon — Downloads

Download the newest version for your computer. You do not need Godot or a GitHub account to play.

- [Download for Windows](https://github.com/DrewbaccaCode/door-dungeon-builds/releases/latest/download/OneThousandDoorDungeon-Windows.zip)
- [Download for macOS (Intel and Apple silicon)](https://github.com/DrewbaccaCode/door-dungeon-builds/releases/latest/download/OneThousandDoorDungeon-macOS.zip)
- [Download for Linux](https://github.com/DrewbaccaCode/door-dungeon-builds/releases/latest/download/OneThousandDoorDungeon-Linux.zip)

Extract the ZIP before running the game. On Windows, open `One Thousand Door Dungeon.exe`; on macOS, open `One Thousand Door Dungeon.app`; on Linux, run `door_dungeon.x86_64`. These are development builds, so Windows or macOS may ask you to approve the downloaded app before it opens.

For online play, enter the relay server's address on the Multiplayer screen, then host a game or join with a room code.

[Latest release and build details](https://github.com/DrewbaccaCode/door-dungeon-builds/releases/latest) · [Automatic build status](https://github.com/DrewbaccaCode/door-dungeon-builds/actions)

This repository contains download releases and publishing instructions. The game's source repository remains private. Each update builds the requested source commit, checks the exported game, uploads all three ZIPs, and only then switches the latest-download links to the new release.
